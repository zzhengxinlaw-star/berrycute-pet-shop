# Berry-Cute Pet Shop

A front-end coursework prototype for a pet shop, built with HTML, CSS, and vanilla JavaScript. It includes a demo sign-in screen, a dog and cat product catalog with interactive previews, a donation page, and a simulated checkout.

## Download or clone

Select **Code → Download ZIP** on GitHub and extract the archive. With Git installed, you can also run:

```sh
git clone https://github.com/zzhengxinlaw-star/berrycute-pet-shop.git
cd berrycute-pet-shop
```

## Run locally

1. Open the project folder and double-click `index.html` to open it in a browser.
2. Click **continue** to open the storefront. You can also open `indexfullpage.html` directly.
3. Explore the product previews and donation and checkout screens. Use sample values only.

Keep the `css`, `img`, `js`, and `video` folders beside the HTML files. The site needs no installation, build step, or local server. Google Fonts requires internet access. The sign-in and checkout screens are demonstrations with no authentication or payment processing.
